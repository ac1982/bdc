=== bdc --help
Usage: bdc <command> [flags]

百度网盘命令行客户端, 为人和 AI agent 而生.

    网盘路径是绝对路径, 或相对于 cd 设定的工作目录; 通配符 * ? [ ] 由 bdc 展开.
    --json: stdout 只有一份 JSON 文档 (含 ok, command, 失败时 error), 进度和日志在 stderr.
    退出码: 0 成功, 1 服务器/网络/传输失败, 2 输入有误 (不存在, 已存在, 无匹配, 提取码错误),
            3 缺少依赖或权限, 4 未登录或登录过期, 64 命令行有误或需要终端, 130 已取消.
    没有终端时不会等待输入: 需要确认的命令要加 -y.

Flags:
      --json       stdout 只输出一份 JSON 文档, 日志和进度在 stderr
  -h, --help       显示帮助
  -v, --version    显示版本

帐号
  login     登录百度帐号
  logout    退出当前帐号
  who       显示当前帐号
  users     列出已登录的帐号
  su        切换帐号
  quota     显示网盘容量

浏览
  ls (ll)    列出目录
  tree       以树形列出目录
  meta       显示文件或目录的详细信息
  search     按文件名搜索
  cd         切换工作目录
  pwd        显示工作目录

管理
  mkdir              创建目录
  rm                 删除文件或目录 (进入回收站)
  cp                 复制文件或目录
  mv                 移动或重命名文件或目录
  recycle list       列出回收站
  recycle restore    还原文件
  recycle delete     彻底删除文件
  recycle clear      清空回收站

传输
  download          下载文件或目录
  upload            上传文件或目录
  offline add       添加离线下载任务
  offline list      列出任务
  offline cancel    取消任务
  offline delete    删除任务记录
  offline clear     清除已结束的任务记录

分享
  share create    创建分享链接
  share list      列出我的分享
  share cancel    取消分享
  share save      把别人的分享转存到我的网盘

其他
  config show     显示设置
  config set      修改设置
  config reset    恢复默认设置
  update          检查并安装新版本
